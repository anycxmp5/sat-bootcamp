# SAT Boot Camp

Сайт для подготовки к Digital SAT: курс по всем темам, практика, 8 пробных тестов (с официальным таймером и без), Exam Guide, личный кабинет.

## Запуск
Откройте `index.html` двойным кликом. Сервер не нужен. Шрифты подгружаются из Google Fonts (без интернета сайт работает на системных).
Прогресс хранится в браузере (`localStorage`); перенос на другой компьютер — «My Locker → Экспорт / Импорт».

## Что внутри
- **Course** — 38 тем: 10 по Reading & Writing и 28 по Math (все навыки спецификации College Board). В каждой теме урок и 8–10 заданий; для многих тем есть кнопка «∞ Extra drill» с новыми заданиями из генератора.
- **Exam Guide** — структура экзамена, время, адаптивность, формат ответов, инструменты Bluebook, чек-лист дня теста.
- **Practice Tests** — 8 полных тестов по 98 заданий: 4 модуля, адаптивный 2-й модуль, перерыв 10 мин, флажки, вычёркивание, калькулятор и справочный лист, режимы Timed / Untimed.
- **My Locker** — статистика, график баллов, слабые темы, история тестов, профили, экспорт/импорт.

## Школьная мотивация (js/campus.js)
Ученический билет (Student ID с талисманом, классом и целевым баллом), уровни Freshman → Valedictorian по XP, 18 значков («Varsity Letter», «All-Star», «Hall of Fame» и др.), табель с оценками A–F и GPA, цель дня, совет тренера, конфетти при успехах.

## Структура кода
- `js/core.js` — структура экзамена, хранилище, проверка ответов, оценка баллов, генераторы
- `js/views.js` — экраны; `js/exam.js` — движок теста; `js/main.js` — роутер
- `data/rw-*.js`, `data/math-*.js`, `data/extra*.js` — темы, уроки и написанные вручную задания
- `data/gen-math.js`, `data/gen-rw.js` — генераторы заданий (подмешиваются в тесты и в Extra drill)

## Как добавить задания
Вручную — в `questions` нужной темы или через `SAT.extend('id-темы', [...])`:

```js
mc(2, 'Вопрос?', ['A', 'B', 'C', 'D'], 1, 'Объяснение', '<p>Текст-пассаж (необязательно)</p>'), // выбор; ответ — индекс 0–3
sp(2, 'Вопрос?', ['5/2', '2.5'], 'Объяснение'),                                                 // ввод числа
```

Первое число — сложность 1–3. Позиции правильных ответов перемешиваются автоматически (не пишите в объяснениях «вариант B» — такие вопросы не перемешиваются).
Генератор — функция `(rnd) => вопрос`, регистрируется через `SAT.addGens('id-темы', [fn])`.

## Соответствие формату оригинала (проверено автоматически)
- Формулировки вопросов R&W — как в Bluebook («Which choice best states the main purpose of the text?» и т. д.); все вопросы — 4 варианта.
- Math в тестах: ≈28% заданий с вводом ответа (в оригинале ≈25%), остальные — с 4 вариантами; числовые варианты упорядочены по возрастанию.
- Позиции верных ответов равномерны; длина вариантов в R&W выровнена (`data/patch-rw.js`), чтобы верный ответ не угадывался по длине.
- Состав модуля по доменам — по спецификации (R&W: 28/26/26/20%; Math: 35/35/15/15%); 2-й модуль адаптивен.

## Оговорки
- Все задания авторские (официальные тесты College Board защищены авторским правом). Для контроля пройдите официальные тесты в Bluebook.
- Баллы приблизительные: официальная шкала пересчёта для каждого теста не публикуется.
- Между 8 тестами Math различается примерно на 92%, R&W — на 59%: задания по пониманию текста (Central Ideas, Inferences, Synthesis) написаны вручную, и их ограниченное число повторяется. Внутри одного теста повторов нет.
- Тексты в R&W короче, чем на настоящем экзамене (в среднем 30–60 слов против 50–100): для практики приёма этого достаточно, но на настоящем тесте текст будет длиннее.
